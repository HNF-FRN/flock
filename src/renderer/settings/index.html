Name each window after its account

“Work — Claude” in Alt+Tab, Win+Tab and taskbar previews, Claude’s icon in the account’s colour there, and a taskbar button per account. Windows keeps these on the window itself; Flock gives each window its own name and icon back when you switch this off or quit.

A slim line in the account’s colour above Claude’s title-bar controls; the window you’re typing in glows. It never covers Claude’s content, takes no clicks, and is left out of screenshots and screen sharing.

Phone

Start Claude Code on this PC from your phone, in any account and any project folder, even a new one, and work in it from the Claude app. Handy when you're away and no session has Remote Control on, or a session's context is full.

Scan this with your phone

In Flock for Android, tap Scan the code. On any other phone, scan it with the camera: Flock opens in the browser, paired with this PC; add it to your home screen. The code holds the key to this PC: don't share it.

Signing in

Each new account signs in once, in its own window, and stays signed in.

  • E-mail — choose Continue with email, then click the sign-in button in the e-mail. While an account waits for sign-in, Flock sends that link to its window and keeps it away from Main.
  • Google — works too. Windows hands the browser's sign-in to Main; Flock passes it on to the waiting account's window (Main ignores a sign-in it didn't start).
  • If Main ever shows a “Use verification code” page, ignore it — never click Sign in here instead there, or Main switches to that account.
  • Connectors in an extra account (Drive, GitHub…): right-click it in the island → Pass the next claude:// link here, then connect.
